05 / dúvidas

Antes de começar,
algumas respostas.

Preciso ter logo ou fotos profissionais?+

Não. A gente trabalha com o que o negócio já tem e, se precisar, a Sett também cria a identidade visual.

As prévias do portfólio são de clientes?+

Ainda não. São sites que criamos para negócios reais de Niterói, com informações públicas, para mostrar como trabalhamos. Quando virarem clientes, contamos aqui.

O site aparece no Google?+

Ele é construído para ser encontrado: nome, endereço, horário e serviços no formato que o Google lê.

Quanto custa?+

Depende do que o negócio precisa. Numa conversa rápida pelo WhatsApp a gente entende o caso e passa o valor.
